# 知乎运营指南 - AI副业指南

---

## 一、账号准备

### 1.1 人设定位
- **一句话介绍**：AI副业实战派，分享已验证的AI变现方法
- **个人简介**：AI副业实践者 | 分享AI变现方法、工具推荐 | 所有教程整理在 aifuye.net | 欢迎交流
- **专业领域**：AI副业、AI工具、内容创作、自由职业
- **教育/职业**：（如实填写，增加可信度）

### 1.2 冷启动策略
- 前7天每天回答3-5个问题
- 优先答「0回答」「少回答」的问题（曝光机会大）
- 前10条回答严格控制质量（不少于800字）
- 不要在前10条回答中放网站链接

### 1.3 权重提升
知乎的排序和推荐由以下因素决定：
- **赞同率**（权重最高）
- 反对率低
- 收藏/喜欢数
- 回答长度（800字以上为佳）
- 账号活跃度

---

## 二、内容策略

### 2.1 回答选题标准
优先选择以下问题：
1. 浏览量 > 1000，回答数 < 50
2. 和AI副业/工具/赚钱相关
3. 问题本身有讨论价值
4. 发布时间在近3个月内

**搜索关键词：**
- AI副业、AI赚钱、AI工具推荐
- ChatGPT副业、AI写作、AI绘画
- 副业刚需、宝妈副业、学生副业
- 自由职业、居家办公、被动收入

### 2.2 回答结构模板
```
开头：共鸣/反问（1-2句吸引注意）
    ↓
正文：分点展开（3-5个要点，每点150-300字）
    ↓
案例：个人经验或数据（增强可信度）
    ↓
总结：核心观点提炼
    ↓
延伸：自然引导至网站（比例不超过内容的20%）
```

### 2.3 想法发布节奏
- 每天2-3条想法
- 早上9点：实用技巧类
- 中午12点：行业观察/观点类
- 晚上8点：工具推荐/经验分享
- 每条想法带2-3个相关话题

---

## 三、引流转化

### 3.1 安全引流方式
知乎对引流比较严格，循序渐进：

**第一阶段（前15天）：不引**
- 纯分享干货，建立专业形象
- 积累赞同和粉丝

**第二阶段（15-30天）：微引**
- 回答结尾用一句话带过
- 「更多详细教程可参考我整理在 aifuye.net 的内容」
- 占比不超过回答的10%

**第三阶段（30天后）：合规引**
- 在回答中自然提及网站2-3次
- 个人简介中放链接
- 开通付费咨询（定价1-5元），在咨询中推资源

### 3.2 禁止操作
- ❌ 在想法区频繁放外链
- ❌ 私信群发推广
- ❌ 在其他高赞回答评论区引流
- ❌ 回答内容大部分在推网站

## 四、长期运营

### 4.1 每周节奏
| 日期 | 动作 |
|------|------|
| 周一 | 发2条回答 + 3条想法 |
| 周二 | 发1条回答 + 2条想法 |
| 周三 | 发2条回答 + 3条想法 |
| 周四 | 发1条回答 + 2条想法 |
| 周五 | 发2条回答 + 3条想法 |
| 周六 | 回复本周所有评论 |
| 周日 | 数据复盘 + 下周选题规划 |

### 4.2 月度目标
- 月发布回答：30-40条
- 月发布想法：60-80条
- 月赞同增长：100+
- 月粉丝增长：50+
- 网站来源（知乎）：日均10-30 IP

### 4.3 数据监测
关注「知乎创作者中心」的：
- 阅读量趋势
- 赞同/收藏/喜欢比
- 粉丝增长来源
- 热门回答排行

保持每周复盘，找出数据最好的回答特征。
